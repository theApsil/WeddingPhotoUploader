# Памятка для гостей (QR / распечатка)

1. Откройте ссылку с приглашения или QR-код — страница «Загрузить фото».
2. Нажмите **«Из галереи»** (готовые снимки) или **«Камера»** (снять сейчас).
3. Можно выбрать несколько фото сразу.
4. Нажмите **«Отправить фото»** и дождитесь зелёной отметки «готово».
5. Если сеть оборвалась — у файла появится кнопка **«Повторить»**.
6. Посмотреть общие снимки можно во вкладке **«Галерея»**.

Авторизация не нужна. Лучше Wi‑Fi, если фото тяжёлые.
HEIC с iPhone тоже принимается (лимит размера указан на странице).
